# 产品设计：Codex Local Remote

## 1. 产品定义

Codex Local Remote 是一个面向个人电脑的自托管浏览器工作台。用户离开
电脑后，只需在安卓手机或其他现代浏览器中打开一个 HTTPS 地址并输入
密码，即可继续使用本机 Codex 项目。

它服务于两个互补场景：

1. **托管对话**：由 Sidecar 创建的对话具有完整远程能力。
2. **桌面快照**：由原生桌面 App 创建的对话提供历史和已持久化进展的
   只读视图。

Sidecar 启动 Desktop 随附的独立 app-server，并与 Desktop 共享持久化任务
历史；因此远程新建的任务会出现在 Desktop。只有该 Sidecar 自己启动的 turn
具备实时事件、追加要求和停止能力，Desktop 进程已经运行的 turn 不能被它
实时订阅或控制。

产品不把技术边界隐藏起来。托管对话显示“可控制”，桌面快照显示
“只读快照，可能延迟”。

## 2. 目标用户与核心任务

目标用户已经在 Windows Codex 桌面端维护多个本机项目，希望使用普通
安卓浏览器完成以下任务：

- 查看电脑上正在进行什么；
- 在已有项目中开始一个新任务；
- 在任务偏离时追加要求或停止；
- 查看是否需要审批以及哪些文件被修改；
- 查看子智能体各自在做什么；
- 判断额度与上下文是否足够；
- 下载项目中的结果文件。

手机不要求安装应用、扩展或 Tailscale。添加到主屏幕仅是可选增强。

## 3. 成功标准

- 首次登录除密码外没有第二套账号体系。
- 从首页到在已有项目中发出新任务不超过三次主要点击。
- 运行状态、等待审批、失败、断线和完成状态不依赖颜色才能理解。
- 360 CSS px 宽度下没有页面级横向滚动。
- 所有主要触控目标不小于 44×44 CSS px。
- 重连后不会重复插入事件，也不会丢失当前子智能体或草稿。
- 原始协议名和 JSON 默认不可见。
- 用户能一眼区分“可控制的托管对话”和“只读桌面快照”。
- 验收追求桌面端与手机端的任务语义一致，而不是逐像素复制：同一任务的
  状态、工作摘要、工具活动、文件变更、子智能体和可用动作必须能对应，
  手机布局则按单手触控重新组织。

## 4. 功能范围

本章先描述首个公开版本的可交付范围；标注“后续增强”的条目属于产品方向，
不代表当前版本已经实现。

### 4.1 登录与会话

- 本机交互式设置一个至少 15 字符的密码或长口令短语；
- 新浏览器输入密码后建立安全会话；
- 查看并退出当前会话；
- 退出全部会话与浏览器内修改密码（后续增强；当前可在电脑本机维护，修改
  密码会撤销旧会话）；
- 登录限速、渐进退避与临时锁定；
- 会话空闲过期和绝对过期。

### 4.2 首页

- 电脑、Sidecar、Codex 与公网入口的分层状态；
- 正在运行的托管对话；
- 最近项目和最近对话；
- 额度摘要；
- “新建对话”主行动。

### 4.3 项目

- 从已有线程的工作目录发现项目，但只用于历史归类和展示；
- 只有在电脑本机显式注册的项目根，才可用于新建对话和文件访问；
- 验证目录存在、可访问且未越过允许范围；
- 最近使用；
- 搜索、收藏、Git 分支和工作区状态（后续增强）；
- 在选定项目中创建新对话。

第一版将单一工作目录视为一个项目。多目录项目只在官方协议稳定暴露相应
语义后加入。

### 4.4 新建托管对话

- 输入任务；
- 从实时模型目录选择模型与支持的思考等级；
- 选择只读、可编辑项目或按需询问权限模式；
- 选择协作模式；
- 创建线程并立即开始第一轮；
- 自动进入实时对话页。

### 4.5 托管对话

- 历史用户消息和助手正文；
- 流式助手正文；
- 思考/工作摘要；
- 聚合后的工具活动；
- 命令状态与有界输出；
- 文件变更、行数统计和 diff；
- 审批与结构化提问；
- 追加引导、停止；
- 下一轮模型与思考等级；
- 上下文使用、自动压缩提示与空闲托管对话的手动压缩；
- 失败详情与恢复建议。

### 4.6 子智能体

- 运行中、等待、完成、失败和取消状态；
- 父子层级及扁平降级视图；
- 进入任何仍有持久化记录的子智能体；
- 查看它的消息、摘要、工具和文件变更；
- 返回父对话并恢复滚动位置；
- 已完成子智能体不会从导航中消失；
- 子线程只读且父对话由 Sidecar 托管时，可通过父智能体转交补充要求；
- Desktop 快照及其父 turn 不显示转交、输入或停止入口。

### 4.7 额度与上下文

- 每个额度窗口的已用/剩余百分比；
- 重置绝对时间和相对时间；
- 限制类型、套餐与 credits（服务返回时）；
- 日使用量与累计统计（服务返回时）；
- 当前线程 token 使用和模型上下文窗口；
- 手动压缩只把 HTTP 接受显示为“已受理”；必须收到压缩项和整轮完成事件才
  显示“上下文已压缩”；
- 自动或手动触发的官方 `contextCompaction` 都显示状态卡片；协议未提供来源
  时不猜测触发方式；
- 缺失数据明确显示“暂时无法读取”，不以 0 代替。

### 4.8 文件

- 只浏览注册项目根；
- 文件夹导航和搜索；
- 文本、Markdown、图片和 PDF 预览；
- 二进制元数据；
- 单文件下载；
- 本轮变更文件打包下载（后续增强）；
- 大小、数量和并发限制；
- 明确的无权限与越界错误。

### 4.9 审计与诊断

- 首版提供不含敏感正文的能力、版本、连接状态和降级诊断；
- 登录、退出、创建线程、引导、停止、审批、下载和设置变更的持久化审计
  及按时间、动作、项目过滤属于后续增强；
- 任何版本都不记录密码、Cookie、提示词、回复正文、文件内容或完整命令
  输出；
- 原始协议诊断只允许在本机显式开启且必须有上限。

### 4.10 离线与恢复

- SSE 自动重连和 `Last-Event-ID` 补偿；
- 超出内存事件窗口后从线程快照恢复；
- 离线保留静态应用外壳；持久化离线浏览已渲染对话属于后续增强；
- 草稿本地保存；
- 恢复连接前禁用审批、停止和下载等实时动作；
- 网络切换、浏览器后台切回和电脑睡眠后的恢复。

## 5. 信息架构

移动端底部导航：

1. 首页
2. 对话
3. 文件
4. 设置

桌面端采用三栏：

- 左栏：项目、对话与主导航；
- 中栏：对话和固定输入区；
- 右栏：子智能体、额度、审批与文件检查器。

## 6. 关键交互

### 6.1 新建任务

```text
首页 → 新建对话 → 选择项目 → 输入需求
     → 选择模型/思考/权限 → 开始 → 实时对话
```

### 6.2 托管对话运行中追加要求

运行时输入区文案为“追加要求，不会中断当前工作”。发送后调用 steer。
模型和思考选择器保持锁定，并提示“新的选择将在下一轮生效”。
Desktop 快照不显示输入、steer 或停止入口，只显示已持久化内容和可能延迟
提示。

### 6.3 子智能体导航

手机使用缩进列表或全屏页面，不使用横向组织图。进入子智能体后顶部显示
父对话面包屑和只读/可转交状态。

### 6.4 审批

审批使用持久的底部抽屉，而不是一闪而过的 Toast。展示影响范围、具体
变更和可选结果。默认不提供永久授权全部操作。

## 7. 视觉方向

白色提供空间，深灰承载信息，绿色只用于品牌、主要行动、当前选择和进度。
警告、危险和信息状态使用独立颜色及文字/图标。

核心设计变量：

```css
--green-700: #0b6b3a;
--green-600: #0f7a43;
--green-500: #18a05e;
--green-100: #e8f6ee;
--green-50: #f4fbf7;
--text-primary: #142019;
--text-secondary: #56635b;
--surface: #ffffff;
--surface-subtle: #f7f9f7;
--border: #e1e8e3;
--warning: #a86600;
--danger: #b42318;
```

- 手机页面水平边距 16px；
- 主要按钮高度 44–48px；
- 卡片圆角 14px；
- 抽屉圆角 20px；
- 正文 16px/1.65；
- 兼容 `100dvh`、安全区、地址栏伸缩和软键盘；
- 遵守 `prefers-reduced-motion`。

## 8. 浏览器验收场景

固定视口：

- 360×800
- 390×844
- 412×915
- 768×1024
- 1280×800
- 1440×900

每个主要视口验证：首页在线、运行中托管任务、新建对话、托管任务实时输出、重复工具
聚合、文件变更、三层子智能体、审批、断线、失败、额度临界、长路径和
200% 字体缩放。

除自动截图外，验收者必须亲自完成完整路径，确认不需要猜测图标、状态或
下一步操作。

## 9. 非目标

- 远程桌面或逐像素镜像原生窗口；
- CLI/TUI 产品界面；
- 公网 shell、任意命令或任意磁盘管理；
- 模型隐藏思维链；
- 无支持接口的桌面活动 turn 控制；
- 多用户团队协作、云同步或 SaaS 托管。
