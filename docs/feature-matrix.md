# 功能边界矩阵

Codex Desktop 与 Sidecar 连接同一个回环 Broker 和单一 app-server。任务
能力不再按“托管对话 / 桌面快照”拆分，而是按工作目录授权区分为注册项目
对话与隔离的无项目对话。

| 功能                            | 注册项目对话                  | 无项目对话                    | 约束                                              |
| ------------------------------- | ----------------------------- | ----------------------------- | ------------------------------------------------- |
| Desktop 与手机看到同一任务      | 支持                          | 支持                          | 使用同一 `threadId`、`turnId` 和 rollout          |
| 任一端创建后实时出现在另一端    | 支持                          | 支持                          | 每个连接都必须完成 `thread/resume`                |
| 全部运行任务实时清单            | 支持                          | 支持                          | 合并 Desktop/Sidecar loaded 集合；不截前三条      |
| 手机新建第一轮                  | 支持                          | 支持                          | Desktop 未连接或订阅屏障失败时拒绝执行            |
| Sidecar 离线时 Desktop 独立使用 | 支持                          | 支持                          | Broker 与 app-server 必须健康                     |
| 查看历史消息                    | 支持                          | 支持                          | 由 app-server 持久化                              |
| 从手机恢复桌面历史任务          | 支持                          | 支持                          | 先调用 `thread/resume`，成功后才出现控制入口      |
| Desktop 置顶顺序                | 只读镜像                      | 只读镜像                      | 首屏按“置顶 / 最近”分组；Web 不改置顶             |
| 重命名与复制对话 ID             | 支持                          | 支持                          | 重命名走官方协议；复制只在当前浏览器本地完成      |
| 归档与恢复对话                  | 支持                          | 支持                          | 运行中/待审批先停止；提交后回读双列表且不重复写入 |
| 实时助手正文                    | 支持                          | 支持                          | 短抖动宽限重连；真断线仍可编辑草稿并按游标恢复    |
| 思考/工作摘要                   | 支持官方暴露的摘要            | 支持官方暴露的摘要            | 运行中只显示最新摘要；完成后保留完整公开历史      |
| 工具与文件变更                  | 支持                          | 支持                          | 仅展示 app-server 公开事件                        |
| 追加引导                        | 运行中支持                    | 运行中支持                    | 连接和 turn 身份必须匹配                          |
| 停止当前回复                    | 支持                          | 支持                          | 连接和 turn 身份必须匹配                          |
| 下一轮排队                      | 支持                          | 支持                          | 待发送正文由 Sidecar 以当前用户 DPAPI 加密持久化  |
| 排队编辑、排序、删除和手动发送  | 支持                          | 支持                          | 修订号冲突时失败关闭并要求重新同步                |
| 当前轮热切换模型/思考           | 不支持                        | 不支持                        | 选择不会改变运行中的 turn                         |
| 下一轮模型/思考/速度            | 支持                          | 支持                          | 选项来自运行时模型目录；不按版本号写死            |
| 权限配置与审批路由              | 运行时提供时支持              | 运行时提供时支持              | 动态读取权限配置；未知值不自动放行                |
| 计划模式与任务目标              | 运行时提供时支持              | 运行时提供时支持              | 直接调用官方协作模式和目标接口                    |
| 审批                            | 请求提供选项时支持            | 请求提供选项时支持            | 动态映射实际选项；缺失时只显示阻塞，不猜按钮      |
| 结构化提问                      | 支持                          | 支持                          | 问题、动态选项和自由文本按原请求提交              |
| 额度与重置时间                  | 服务返回时支持                | 服务返回时支持                | 与工作目录类型无关                                |
| 上下文使用                      | 服务返回时支持                | 服务返回时支持                | 缺失时不以 0 代替                                 |
| 上下文压缩状态                  | 自动或手动触发时显示          | 自动或手动触发时显示          | 以真实完成事件为准                                |
| 手动压缩上下文                  | 空闲且可控时支持              | 空闲且可控时支持              | 运行中不可发起                                    |
| 子智能体列表                    | 支持，层级 API 缺失时扁平降级 | 支持，层级 API 缺失时扁平降级 | 已完成子任务保留导航                              |
| 回答图片与已查看图片活动        | 支持                          | 支持                          | 缩略图可展开；原图可预览或下载                    |
| 新建任务 cwd                    | 本机注册并复核身份的项目根    | 安装时配置的隔离临时根        | 手机不能提交任意绝对路径                          |
| 全磁盘文件浏览与搜索            | 支持                          | 支持                          | 独立文件页；同一用户的管理员后台任务              |
| 预览、下载与完整文本复制        | 支持                          | 支持                          | 文本/Markdown/图片/PDF 有界预览；原文件可下载     |
| 上传、新建、编辑、重命名        | 支持                          | 支持                          | 登录、同源、CSRF、幂等与明确覆盖确认              |
| 复制、移动与删除                | 支持                          | 支持                          | 默认进入回收站；永久删除必须再次明确确认          |
| 将目录登记为项目                | 仅电脑本机支持                | 不适用                        | 手机不能扩大文件授权范围                          |

“不支持”项不会显示一个看似可用但实际无效的按钮。Broker 和 app-server
原始 WebSocket 永不通过公网入口暴露。Windows Desktop 共享模式依赖
fail-open 启动器按进程使用隐藏的 `CODEX_APP_SERVER_WS_URL` override；
项目不持久写入该变量。普通 vendor 启动、Codex 更新、Windows reboot 和
sleep/resume 始终原生。固定 DataDir dispatcher 的显式 Open 是唯一接管原因；
`RunAs` 安全入口只是 `Open -AllowDesktopRestart` 的可选别名。
`Interactive` / `Highest` 按需任务中的 coordinator 是唯一受管 Desktop
process owner，并从同用户、同会话的 medium-integrity Explorer primary
token 创建 attached Desktop。已 ready 时 Open 零重启；兼容 Web/Sidecar 更新
只滚动公网层；只有 Open 明确授权时才可对精确 native root 执行一次交接。
Remote 不可达时保留或恢复原生 Desktop，且不能循环重启。每次 Desktop 或
随附 Codex 升级后的共享任务能力仍必须重新实机验收。

排队区不是 Desktop 原生草稿的镜像：app-server 没有暴露 Desktop 未发送
队列的读写接口。Web/手机待发送项由 Sidecar 持久化并实时同步给已登录浏览器；
只有真正派发成功后，Desktop 才会出现该用户消息。产品不会把尚未派发的
Sidecar 队列伪装成 Desktop 已经可见。

若 app-server 对某条历史任务没有返回可靠的模型、思考等级或上下文用量，
界面显示“未知 / 暂不可用”，不会用默认模型、默认思考或 0% 冒充真实值。

“新建任务 cwd”和“电脑文件”是两条独立边界。登记项目只决定手机能把新任务
启动在哪个项目根；文件页不因任务是否关联项目、文件是否隐藏或扩展名类型而
降权，它枚举 Sidecar 当前管理员后台任务可访问的本机磁盘，并允许同一身份
可以完成的上传、新建、编辑、复制、移动、重命名、回收站删除和显式永久删除。
绝对文件链接使用当前会话内的短时不透明授权，不会生成可长期复用的公网裸链。

Sidecar 每个健康轮询周期都会同时核对受管启动回执、Broker 运行代号、进程
身份和 `/ready` 中的 Desktop/Sidecar 连接状态。状态变化会立即触发浏览器
刷新；Desktop 断开、回执缺失或实时协议探针失败时，新建和执行入口失败
关闭。仅检测到已安装版本身份漂移时，现有已验证运行链在模型/任务探针继续
通过的前提下保持可用并显示待切换提示。
