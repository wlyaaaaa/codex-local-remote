# 功能边界矩阵

“托管对话”由 Codex Local Remote 自己启动的 app-server 创建；“桌面快照”
由原生 Codex 桌面进程创建，另一个进程只能读取已持久化状态。

| 功能                  | 托管对话                      | 桌面快照                                     |
| --------------------- | ----------------------------- | -------------------------------------------- |
| 查看历史消息          | 支持                          | 支持，可能延迟                               |
| 实时助手正文          | 支持                          | 不支持实时订阅；仅显示已持久化正文，可能延迟 |
| 思考/工作摘要         | 支持官方暴露的摘要            | 仅已持久化摘要                               |
| 隐藏完整思维链        | 不支持                        | 不支持                                       |
| 工具与文件变更        | 支持                          | 仅已持久化内容                               |
| 追加引导              | 运行中支持                    | 不支持                                       |
| 停止当前回复          | 支持                          | 不支持                                       |
| 当前轮热切换模型/思考 | 不支持                        | 不支持                                       |
| 下一轮更换模型/思考   | 支持                          | 新建托管轮次时支持                           |
| 审批                  | 支持                          | 不支持                                       |
| 额度与重置时间        | 服务返回时支持                | 与对话模式无关                               |
| 上下文使用            | 服务返回时支持                | 仅已持久化信息                               |
| 上下文压缩状态        | 自动或手动触发时显示          | 仅已持久化信息                               |
| 手动压缩上下文        | 空闲且可控时支持              | 不支持                                       |
| 子智能体列表          | 支持，层级 API 缺失时扁平降级 | 只读快照                                     |
| 进入已完成子智能体    | 有持久化线程时支持            | 有持久化线程时只读                           |
| 选择项目创建新对话    | 支持                          | 创建后属于托管对话                           |
| 浏览/下载项目文件     | 注册项目内只读                | 注册项目内只读                               |

“不支持”项不会显示一个看似可用但实际无效的按钮。实验性协议能力缺失
时，页面显示具体降级原因，核心聊天仍可使用。
